# App Support

Public entry point: https://peterombodi.github.io/caesar-privacy-policy/support/

- English: `en/index.html`
- Ukrainian: `ua/index.html` (`lang="uk"`)
- Shared appearance: `style.css`

To add a language, copy a localized page to a new folder such as `de/index.html`,
translate its content and metadata, and set the HTML `lang` attribute.
Add the new language to the navigation and alternate-language links on every
support page. Keep the existing URLs stable. Link to a matching privacy policy
when available, or to the English iOS policy otherwise.

These static files are published with the existing GitHub Pages site.
